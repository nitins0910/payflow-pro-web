How to Generate Bank Payment Files

A complete walkthrough — from adding employees to uploading the file to your bank.

This guide covers the full export flow for all 4 currently supported banks — SBI, HDFC, ICICI, and PNB. Each bank's file uses that bank's exact corporate bulk-upload format, so the file PayFlow Pro generates can be uploaded to your bank's net-banking portal as-is — no manual reformatting needed.

1. Before you start

Make sure these two things are set up once (you won't need to repeat them for future payroll runs):

  1. Your company's bank account is set up in Settings.

    Go to Settings → Edit Company Details and enter your company name, the bank you hold your account with (SBI / HDFC / ICICI / PNB), your account number, and your IFSC code. This is the account salaries are debited from, and PayFlow Pro uses it to pick the correct file format automatically.

  2. Your employees are added with correct bank details.

    On the Employees page, each employee needs their name, employee code, bank account number, and IFSC code filled in correctly. A wrong IFSC or account number will carry straight through into the bank file, so it's worth double-checking these once when you add someone.

2. Register employees as beneficiaries (one-time, per bank)

Before an employee can actually receive a payroll transfer through your bank's bulk upload, most banks first require them to be registered as a Beneficiary / 3rd Party / Payee on your bank's own net-banking or CMS portal. This is a separate, one-time step from generating the payroll payment file in Section 3 below — skip it and your bank may bounce or reject the transfer even though PayFlow Pro shows the export as successful.

  1. Go to Employees → "📄 Beneficiary Upload File" (marked FREE).

    This is a free companion tool — it never touches your wallet/credits, since it's unrelated to the paid payroll export. It builds the beneficiary registration file straight from your saved employee list.

  2. Download the file for your bank's format.

    SBI gives you two separate files — one for Same Bank (Intra) beneficiaries and one for Other Bank (Inter) beneficiaries. PNB, ICICI, and HDFC each give a single combined file in their own bulk-beneficiary template.

  3. Upload it to your bank's "Add Beneficiary / 3rd Party Payee" section.

    Look for this under your bank's Net Banking / CMS Corporate portal — usually filed under "Payee Management" or "Manage Beneficiary".

  4. Wait for your bank's activation/cooling period before the first payout.

    Most banks hold a newly added beneficiary for a few hours (sometimes up to 24–30 hours) before allowing payments to them, as an anti-fraud measure. Plan a new joiner's first payroll run with this in mind.

You only need to re-generate and re-upload this file when you add a new employee, or when an existing employee's bank account or IFSC changes. Employees already registered as beneficiaries don't need to be re-added for every payroll cycle.

3. Run payroll and export the file

  1. Open Generate Transaction File from the top navigation.

    You'll see every employee listed with an editable amount field.

  2. Choose Transfer Type — Intrabank Transfer or Interbank Transfer.

    Intrabank Transfer shows only employees whose account is with your own bank (matched by IFSC prefix) — these move as a low-cost internal transfer. Interbank Transfer shows everyone else, who get paid via NEFT, RTGS, or IMPS depending on the amount and your bank's format.

  3. Optionally toggle "Prefer IMPS" (only shown for banks that support it — currently SBI).

    When this is on, eligible cross-bank payments are marked IMPS instead of NEFT/RTGS — useful for same-day/instant credit for smaller amounts.

  4. Set the Payroll Cycle and Transfer Date.

    These are stamped into the file header/records so the bank knows which salary month and value date the batch is for.

  5. Review the amounts and the auto-assigned Mode column, then click Export File.

    This consumes 5 credits from your wallet. New accounts start with 50 free credits (ten exports' worth); once your balance runs low, a "Buy Credits" prompt lets you top up via Razorpay — pricing gets progressively cheaper per credit on larger packs.

  6. Download and upload the file.

    The file downloads in the exact format your bank's corporate portal expects. Log in to your bank's net-banking / CMS portal, find the bulk salary/NEFT-RTGS upload section, and upload the file directly.

Every export is saved on the Exports page, where you can search by batch ID or bank and re-download any past file. Re-downloaded files reflect your company profile and IFSC exactly as they were at the time of that export, not your current settings — so historical batches always stay accurate even if you later change banks.

4. How the transfer mode is decided automatically

You don't have to pick NEFT vs RTGS vs IMPS per employee — PayFlow Pro works it out for you, per the rules below:

  • Same Bank / Internal — whenever the employee's IFSC starts with your own bank's code (e.g. both accounts are SBI).
  • RTGS — for cross-bank amounts of ₹2,00,000 or more, on banks whose file format supports RTGS.
  • NEFT — the default for smaller cross-bank amounts, and the fallback wherever RTGS isn't supported by that bank's format.
  • IMPS — only if you've turned on "Prefer IMPS" and your bank's format supports it.

5. What each bank's file supports

Not every bank's bulk-upload format has the same capabilities — this is set by each bank's own file specification, not a PayFlow Pro limitation. Here's exactly what's available for each:

State Bank of India (SBI)

IFSC prefix: SBIN
  • Same Bank
  • NEFT
  • RTGS (₹2L+)
  • IMPS (optional toggle)

HDFC Bank

IFSC prefix: HDFC
  • Same Bank
  • NEFT
  • RTGS (₹2L+)
  • IMPS not supported

ICICI Bank

IFSC prefix: ICIC
  • Same Bank
  • NEFT (used for all cross-bank credits, regardless of amount)
  • RTGS not supported
  • IMPS not supported

Punjab National Bank (PNB)

IFSC prefix: PUNB
  • Same Bank
  • NEFT
  • RTGS (₹2L+)
  • IMPS not supported

Note: ICICI's bulk file format has no RTGS line at all, so every cross-bank payment goes as NEFT even above ₹2L. If you need RTGS for a large ICICI transfer, you'll need to do that one manually through net-banking.

6. Frequently asked questions

Can I switch banks later?

Yes — update it any time in Settings → Edit Company Details. Your next export will use the new bank's file format automatically. Past exports already downloaded are unaffected.

My bank isn't in the list — what do I do?

Only SBI, HDFC, ICICI, and PNB have file formats built in today. Message us via Help & Support in the sidebar with your bank's name — if you can share your bank's bulk upload format spec, we can look at adding it.

Why did an employee not show up when I chose "Intrabank Transfer"?

That view only lists employees whose IFSC prefix matches your own company bank. If their account is with a different bank, they'll appear under "Interbank Transfer" instead.

Do I need to register employees with my bank before I can pay them?

Yes — this is a one-time step per employee, separate from the payroll export above. Use the Beneficiary Upload File button on the Employees page to generate your bank's beneficiary registration file, then upload it via your bank's own net-banking portal. See Section 2 above for the full walkthrough.

What happens if I run out of credits mid-export?

Nothing is deducted or generated until you have enough credits for that export (5 credits). If your balance is short, a "Buy Credits" prompt opens so you can top up via Razorpay, then export normally.

Does PayFlow Pro actually transfer the money?

No — PayFlow Pro only generates the file. You upload it to your own bank's corporate net-banking portal, and your bank executes the actual transfers from there.
